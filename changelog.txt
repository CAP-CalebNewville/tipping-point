v2.0.6 10 Nov 2026
==================
* Fixed releases shipping a development database (data/tippingpoint.db) containing a pre-created administrator account; new installs now run the setup flow and upgrades from MySQL-based versions now reach the migration flow
* Fixed "Undefined variable $current_envelope_color" breaking the admin page JavaScript (Create Envelope appeared to fail) on aircraft with no CG envelopes
* Fixed "Undefined array key" warnings on the aircraft selection page (index.php) when tailnumber or message are absent
* Fixed PHP 8.5 deprecation of curl_close()
* Fixed "Undefined array key" warnings for missing request/session values throughout admin.php, ajax_handler.php, index.php, scatter.php and setup.php
* Fixed "Trying to access array offset on false" warnings when editing or deleting records that no longer exist; Edit User now reports "User not found"
* Fixed an uncaught database exception when adding a user without a username
* Fixed new installs being sent to a "remove deprecated columns" screen on first admin login; setup now creates the current schema
* data/*.db files are now excluded from version control

v2.0.5 06 Nov 2026
==================
* Security: fixed unauthenticated creation of administrator accounts through the admin users handler and the setup installer
* Security: added an authorization check to user management and made all authentication redirects stop execution
* Security: the setup installer now refuses to run once a user account exists, preventing installer replay
* Security: removed plaintext password storage from the session and added session ID regeneration on login
* Security: escaped user-controlled output to prevent cross-site scripting on the weight & balance form and the admin users list
* Security: added deny rules for the data directory and include/database files (effective when AllowOverride is enabled)
